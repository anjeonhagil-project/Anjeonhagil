## 해석상의 제한

1. **계수는 시험값이다.** 정규화 1, 범위 0.5~2는 파일럿 설정이다. 무한값·경계 폭주를 막는 수치 검사는 통과했지만 이 범위가 사용자에게 최적이라는 의미는 아니다.
2. **거리 정보가 약하다.** 네 문항, 짧은 거리 차이, 기존 합성 모델의 거리 계수 때문에 시험 결과가 1 근처에 머무를 수 있다. 거리 선호가 없다는 뜻이 아니다.
3. **일부 문항의 모델 확률은 여전히 편향된다.** 특히 Q2에서 한 부담만 선택하면 기존 모델이 부담 감소 쪽을 강하게 선호한다. 문항은행만 바꿔 모델의 합성 데이터 편향까지 해결했다고 할 수 없다.
4. **합류·분기 학습은 보류다.** 원본 답변은 보존하지만 정식 학습 label/계수 추정에는 사용하지 않는다. 추가 데이터 또는 별도의 문항 설계가 필요하다.
5. **새 모델 연결은 다음 단계다.** 팀원의 실제 응답 수집·분리된 검증·재학습 결과를 받은 뒤 feature/scaler/계수 버전을 맞춰 연결한다.
